What it does not do

We would rather you know now than after installing.

  • Work on every phone: it uses your phone's speech recognition, which some phones lack or need internet for
  • Understand every accent perfectly: always check before saving

Questions

Which languages does voice billing support?

English, Hindi, Tamil, Telugu, Kannada, Malayalam, Marathi, Gujarati, Bengali, Punjabi, Odia and Urdu.

Does voice billing need internet?

It uses your phone's own speech recognition. Some phones can do this offline if the language pack is downloaded; others need internet.

What should I say?

Start with "for" and the customer's name, then each item with quantity and price. Pause or say "and" between items.

Can I edit what it heard?

Yes. Everything is editable before you save.
